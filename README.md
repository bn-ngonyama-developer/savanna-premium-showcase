# Savanna Premium Dry Cider – React Consumer Brand Showcase

## Project Overview
This is a modern, component-driven front-end brand showcase web application built using the React framework. The project replicates Savanna's iconic South African "Dry" visual identity guidelines, demonstrating structural multi-view routing, reusable UI component mapping, rich product media arrays, and responsive corporate brand panels.

## Technical Stack
* **Framework:** React (Component-Driven Architecture)
* **Structural Blueprint:** JSX / HTML5 Semantic Elements
* **Design & Alignment Engine:** CSS3 Custom Styling Sheets & Adaptive Flexbox Layouts
* **Data Mocking:** JSON data structures mapping brand campaign parameters

## Key Technical Features
* **Component-Driven Visual Architecture:** Modularized the interface into clean, reusable React components—isolating navigation menus, product display cards, and marketing campaign grids for cleaner code maintainability.
* **Cohesive Corporate Brand Alignment:** Leveraged global CSS variables to lock down Savanna's signature bright yellow marketing identity and high-contrast typography schemas across the application viewport.
* **Dynamic Data Rendering:** Engineered JavaScript array mappings inside the React lifecycle to loop through product matrices, cleanly rendering information blocks for classic Savanna Dry, Savanna Dark, and Angry Lemon bottles.
* **Fluid Layout Responsiveness:** Structured fluid multi-device layout containers using responsive design principles, ensuring text grids and brand media cards scale smoothly across mobile and desktop display viewports.
